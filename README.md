# Overview

I wrote a very simple chat room software that allows clients to connect to a server and communicate with each other. In addition, they can play a simple math game that will ask them to do some basic arithmetic problems. If the client gets the answer correct, they gain a point and their current score is displayed to them and all the other clients. 

[Software Demo Video](https://youtu.be/svt0rOYSgAw)

# Network Communication

I used a client to server architecture.

I used TCP.

Messages are sent to the server which broadcasts the message to all the clients.

# Development Environment

I used Python and a number of libraries including threading, socket, and random.
